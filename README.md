# 🧩 拼图小游戏

这是一个基于 Java Swing 开发的经典拼图小游戏，支持图片选择、随机打乱、步数统计和重置功能。

---

## 📦 项目结构
puzzlegame/
├── src/ # 核心 Java 代码
│ └── ui/ # 界面与游戏逻辑实现
├── image/ # 游戏图片资源（动物 / 美女 / 运动等主题）
└── .gitignore # Git 忽略配置文件

---

## ✨ 功能特性
- 🎨 多套图片主题切换（动物、风景等）
- 🔀 一键随机打乱拼图
- 🔢 实时步数统计
- 🔄 重新游戏、重新登录功能
- 🎮 键盘方向键控制移动

---

## 🚀 运行方式
1.  克隆项目到本地：
    ```bash
    git clone https://github.com/你的用户名/puzzlegame.git
2.  使用 IDEA 打开项目，确保 JDK 版本为 17+
3.  运行 src/ui/GameJFrame.java 主类即可启动游戏

## 📝 开发说明
开发语言：Java
界面框架：Java Swing
核心逻辑：二维数组模拟拼图，随机打乱 + 空格交换实现移动
